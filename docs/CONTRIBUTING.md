# Contributing

Read [WORKING_WITH_AI_AGENTS.md](WORKING_WITH_AI_AGENTS.md) for the task protocol, source-editing cautions and manual QA checklist.

Keep changes on a feature branch and small enough to review. Confirm event facts with the family; do not fill pending dates or destinations by inference. Never modify the original/reference export to make the active page change. Before a content edit, locate the matching HTML responsive variants and MJS page-instance props. Before an image change, preserve original files and compare the full-size before/after result, transparency and every referenced responsive variant.

Do not add private family references, unlicensed media, local environments, or model files. The intended workflow is local development and commits, then collaboration with the owner's brother through a private GitHub repository. Keep that repository private; public distribution and public hosting are not currently intended. See [asset licence notes](IMAGES.md#licensing-and-sharing) for the separate template terms. Do not represent private collaboration as public permission to distribute or host the exported template.
